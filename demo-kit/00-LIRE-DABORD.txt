RÈGLE DE CONTENU
Ce scénario n'est ni une offre réelle ni une étude de marché.
Les prix, conditions, identité et équipements sont inventés pour l'exercice.
La présence du JSON ne confirme aucune capacité ou qualité du véhicule de l'ami de Noa.
Pas de faux SIRET, certificat VTC, assurance, profil Google, note étoilée ou avis client.
Les contacts affichés ne doivent déclencher aucun contact sortant.
Le site conserve une mention discrète de démonstration et des formulaires simulés.

IMPORTANT SUR LE CODE
Ce kit ne contient pas le code du projet Claude. Il apporte uniquement les données,
les images et les consignes à intégrer dans son dépôt actuel.
Il ne faut pas importer le code du prototype MagicPath à la place de son projet Astro.
Le scénario Azuréa existant a été relu et repris ; les nouveaux assets du hero sont
générés spécifiquement pour cette itération de Claude Code.

MODE DÉMO ET BUILD
« Build optimisé de production » décrit une compilation technique.
« Activité réelle » décrit le mode métier. Ces deux notions doivent être séparées.
Un build optimisé en BUSINESS_MODE=demo est permis sans données professionnelles réelles.
BUSINESS_MODE=live conserve les contrôles prévus pour une vraie mise en service.
Le fichier fictif ne peut pas satisfaire ces contrôles en mode live.

QUE DEMANDER À CLAUDE APRÈS INTÉGRATION
Un code/archive accessible, un REVIEW.md actualisé, un aperçu réellement consultable
ou des commandes de lancement local exactes, les captures et les rapports pertinents.
Les scores et tests du compte-rendu initial sont des déclarations de Claude :
ils ne constituent pas encore une revue indépendante du code par ChatGPT.
